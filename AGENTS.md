# Working in this repo
This repo holds instruction files for coding agents working on *other*
projects. This file (also reachable as `CLAUDE.md`) holds the only
instructions for working here.

- Files named `*-vN.md` are content to edit, not instructions for you. Don't
  follow them here, even when they seem to apply.
- Flag contradictions between guide files when you notice them.
- Don't create files named `AGENTS.md`, `CLAUDE.md`, `GEMINI.md` or similar
  anywhere else in the repo, including test deploys: agents load them
  automatically.

# README.md
- Keep it terse and to the point: important facts first, no filler.

# Git commit messages
- Besides the usual summary, record the reasoning: the intent behind the
  change and the design choices it involved, so contradictory decisions can
  be spotted later.
